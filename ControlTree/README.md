[size=5]Control Tree | 树木渲染控制[/size]

通过修改树木的渲染逻辑来实现更好的视觉清晰度的模组。
A mod that aims to achieve better visual clarity by modifying the rendering logic of trees.

[line]

[size=5]目前已经实现的功能:[/size]

[list]
[*]替换小树贴图（可以自定义快捷键）[/*]
[*]缩小成熟的树（可以自定义快捷键）[/*]
[*]高亮树种（可以自定义快捷键）[/*]
[*]高亮树苗[/*]
[*]高亮树种时透明化遮挡树种的树[/*]
[*]摇树是否能产出树种的提示（可以自定义快捷键）[/*]
[*]是否有苔藓的提示（可以自定义快捷键）[/*]
[*]是否渲染成熟树的树干（可以自定义快捷键）[/*]
[*]在不渲染成熟树的树干时，是否渲染树叶的影子（可以自定义快捷键）[/*]
[*]是否渲染树液采集器产物[/*]
[*]设置生效的树的类型[/*]
[/list]

[size=5]配置 / Configuration[/size]

Access the config menu from the game pause menu. All settings can be customized via the Generic Mod Config Menu interface.
