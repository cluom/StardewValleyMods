# Control Tree | 树木渲染控制

**作者 / Author:** Cluom
**Nexus Mods:** [页面 / Page](https://www.nexusmods.com/stardewvalley/mods/23119)
**版本 / Version:** 1.1.5

通过修改树木的渲染逻辑来实现更好的视觉清晰度的模组。 / A mod that aims to achieve better visual clarity by modifying the rendering logic of trees.

---

## 功能介绍 / Features

### 通用设置 / General Settings

- **模组开关** - 一键开启或关闭整个模组，支持快捷键
- **替换贴图** - 使用缩小后的贴图替换树木贴图（需配合纹理包）
- **缩小树木** - 将树木缩小至原来的一半
- **树种提示** - 在有树种的树上显示浮动提示
- **苔藓提示** - 在有苔藓的树上显示浮动提示
- **高亮树种** - 用闪烁的高亮框标记树种位置
  - 可自定义高亮颜色（RGB）
  - 可选择跳过已施肥的树种
  - 可使遮挡树种的树变透明
- **高亮树苗** - 高亮显示只有一格大小的树苗，支持自定义颜色
- **隐藏树液采集器产物** - 隐藏树液采集器的产物（不影响获取）
- **渲染树干** - 取消勾选可将成熟树木渲染成树桩
- **渲染树叶影子** - 取消勾选可在不渲染树干时取消树叶影子

### 树木选择页面 / Tree Selection Pages

配置各项效果适用于哪些树木： / Configure which trees each effect applies to:

- **原版树木 / Vanilla Trees** - 橡树、枫树、松树、蘑菇树、桃花心木、苔藓树1-2、蕨树、神秘树 / Oak, Maple, Pine, Mushroom, Mahogany, Moss Trees 1-2, Fern Tree, Mystic Tree
- **原版果树 / Vanilla Fruit Trees** - 樱桃树、杏树、橙树、石榴树、桃树、苹果树、香蕉树 / Cherry, Apricot, Orange, Pomegranate, Peach, Apple, Banana
- **里奇赛德村果树 / Ridgeside Village Fruit Trees**（需安装 RSV 模组 / requires RSV mod）- 樱桃杏李树、沙漠橘柚树、灰烬血莱姆树、高地醋栗樱桃树、高山李杏树、北方莱姆金柑树、天堂黎檬树、热带丑橘树 / Cherry Pluot, Desert Tangelo, Ember Blood Lime, Highland Jostaberry, Mountain Plumcot, Northern Limequat, Paradise Rangpur, Tropi Ugli Fruit

### 果树成熟浮窗 / Fruit Tree Popup

果树成熟时，会显示包含以下内容的浮动气泡： / When fruit trees are ready for harvest, a popup bubble shows:

- 水果图标 / Fruit icon
- 水果数量 / Fruit count
- 上下浮动动画 / Floating animation

## 需求 / Requirements

- Stardew Valley 1.6+
- SMAPI 4.0.0+
- Generic Mod Config Menu（用于游戏内配置 / for in-game configuration）

### 可选依赖 / Optional Dependencies

- **Ridgeside Village** - 支持里奇赛德村果树 / For Ridgeside fruit tree support

---

## 安装 / Installation

1. 安装 SMAPI
2. 安装 Generic Mod Config Menu
3. 下载并解压本模组到你的 `Mods` 文件夹

---

## 配置 / Configuration

在游戏暂停菜单中可以访问配置菜单。所有设置都可通过 Generic Mod Config Menu 界面进行自定义。

Access the config menu from the game pause menu. All settings can be customized via the Generic Mod Config Menu interface.

### 快捷键 / Keyboard Shortcuts

所有开关选项都可以分配快捷键，以便在游戏过程中快速切换。

All toggle options can be assigned shortcut keys for quick access during gameplay.
